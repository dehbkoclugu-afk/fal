# APK Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and download an installable Telve preview APK from the release-blocker fix branch.

**Architecture:** Reuse the existing GitHub Actions Expo prebuild plus Gradle workflow. Allow fix branches to trigger it, publish the existing fix branch, then verify and download its artifact.

**Tech Stack:** GitHub Actions, Expo 57, Gradle, Android APK

## Global Constraints

- Do not merge the fix branch into the default branch.
- Keep the existing live Railway API URL.
- Do not introduce another build workflow or dependency.

---
