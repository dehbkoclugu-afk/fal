# Rider–Waite–Smith tarot artwork

`rws-atlas.webp` contains all 78 card faces from the original 1909/1910
Rider–Waite–Smith (“Pam-A”) deck, illustrated by Pamela Colman Smith.

- Canonical rights record: Wikimedia Commons, `Category:Rider-Waite tarot deck`
- Source scans: matching public-domain files mirrored by `searge/tarot`
- Rights: Public Domain Mark 1.0. The original deck is public domain in the
  United States, United Kingdom, and Türkiye.
- Processing: 78 source cards placed without recoloring in a 13×6 WebP atlas.
  No modern copyrighted recoloring or card-back artwork is included.

Atlas order matches the backend deck: 22 majors, then 14 each of wands, cups,
swords, and pentacles.
